
# 📝 Todo List (Shell Script Version)

این پروژه یک Todo List ساده است که با استفاده از Bash نوشته شده و روی ترمینال اجرا می‌شود. کاربر می‌تواند کارهایی را اضافه کند، لیست کند، جستجو کند، به‌عنوان انجام‌شده علامت بزند یا همه‌ی آن‌ها را پاک کند.

---

## ⚙️ پیش‌نیازها

برای اجرای درست این اسکریپت، به ابزارهای زیر نیاز دارید:

- **Bash Shell**: این اسکریپت با Bash نوشته شده و باید در محیطی اجرا شود که Bash در دسترس باشد (تقریباً تمام سیستم‌های لینوکسی و macOS).
- **awk** و **sed**: این ابزارها برای پردازش متنی در اسکریپت استفاده شده‌اند و در اکثر سیستم‌های Unix-like به‌صورت پیش‌فرض نصب هستند.
- **فایل `tasks.csv`**: تمام اطلاعات مربوط به کارها در این فایل ذخیره می‌شود. در اولین اجرای دستور `add` این فایل به‌صورت خودکار ساخته می‌شود.

---

## 🧠 این اسکریپت چگونه کار می‌کند؟

### ساختار داده:

کارها در فایل `tasks.csv` به‌صورت زیر ذخیره می‌شوند:

```
<done>,<priority>,<title>
```

- `done`: مقدار 0 یعنی انجام نشده، و 1 یعنی انجام‌شده.
- `priority`: اولویت کار (L, M, H).
- `title`: عنوان کار.

### منطق عملکرد:

- هنگام اجرای دستور `add`: یک خط جدید به انتهای فایل `tasks.csv` اضافه می‌شود.
- هنگام اجرای `list`: لیست کارها با استفاده از `awk` نمایش داده می‌شود و شماره‌گذاری می‌شود.
- هنگام اجرای `done`: وضعیت `done` خط مربوطه به 1 تغییر داده می‌شود.
- هنگام اجرای `find`: از `awk` برای جستجوی کلمه در عنوان کارها استفاده می‌شود.
- هنگام اجرای `clear`: محتویات فایل `tasks.csv` خالی می‌شود.

---

## 🛠️ نحوه استفاده

### اضافه کردن کار جدید:

```bash
bash todo.sh add -t "عنوان کار" -p [L|M|H]
```

- `-t`: عنوان کار (اجباری)
- `-p`: اولویت (اختیاری، پیش‌فرض: `L`)

### نمایش لیست تمام کارها:

```bash
bash todo.sh list
```

### علامت‌گذاری یک کار به‌عنوان انجام‌شده:

```bash
bash todo.sh done <task_id>
```

مثال:

```bash
bash todo.sh done 2
```

### جستجوی یک کار خاص:

```bash
bash todo.sh find <کلمه‌کلیدی>
```

مثال:

```bash
bash todo.sh find خرید
```

### پاک‌کردن تمام کارها:

```bash
bash todo.sh clear
```

---

## 🧪 مثال‌های کامل:

```bash
bash todo.sh add -t "خواندن کتاب" -p M
bash todo.sh add -t "نوشتن گزارش" -p H
bash todo.sh list
bash todo.sh done 1
bash todo.sh find کتاب
bash todo.sh clear
```
